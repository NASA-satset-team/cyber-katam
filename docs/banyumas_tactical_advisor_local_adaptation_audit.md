- Raw precipitation is not treated as effective rainfall for irrigation.

## 3. Decision Rules yang Diselesaikan

### 3.1 Irrigation

Implemented with **sequential `forward_water_balance()`**:

- H+1 uses initial root-zone storage.
- H+2 uses H+1 storage.
- H+3 uses H+2 storage.
- ETc per day = `Kc(stage) × forecast ETo`.
- Effective rainfall is explicit (`ForecastDay.effective_rain_mm`).
- Runoff and deep percolation are explicit inputs; no default zero.
- If drainage/water components are missing → `ABSTAIN`.
- If sequential storage remains at/above field capacity → `DEFER`.
- If a root-zone deficit remains → `CONDITIONAL` (supplemental irrigation; field verification).
- Missing Kc/ETo/effective rainfall/soil hydraulic limits → `ABSTAIN`.
- PVRS is not used as a substitute for soil moisture.

### 3.2 Fertilization

- Requires explicit `n_requirement_kg_ha`.
- Current registry has `null` for all target crops → `ABSTAIN`.
- Rain forecast → `CONDITIONAL` because no approved leaching threshold.
- No automatic conversion of soybean N fixation into fertilizer reduction.
- No Banyumas fertilizer dose is created from outside-region research.

### 3.3 Drainage

- Requires soil moisture and saturation.
- Forecast rainfall is supporting information, not proof of waterlogging.
- Storage at/above saturation + rain → `CONDITIONAL`, not a final `RECOMMENDED`, because local drainage capacity/outlet condition/threshold is missing.
- Missing soil/saturation → `ABSTAIN`.
- No universal drainage threshold.

### 3.4 Planting

- Requires crop duration.
- Rain forecast → `CONDITIONAL`.
- Missing duration/soil moisture → `ABSTAIN`/`CONDITIONAL`.
- No planting window/KATAM threshold is invented.
- Strategic rotation is not changed by H+1–H+3 forecast.

### 3.5 Harvest

- Requires planting date + growing duration.
- If planting date/duration missing → `ABSTAIN`.
- If duration is a range → `CONDITIONAL`; no single maturity claim.
- If forecast date is before registry-duration maturity date → `CONDITIONAL` “do not claim harvest readiness.”
- If no field maturity indicator (grain moisture, NDVI/NBI/field check) → remains `CONDITIONAL`; no final harvest-readiness claim.
- No outside-region NDVI/NBI threshold is used as a Banyumas threshold.

### 3.6 Fallow

- Uses supplied BF-EHSI only.
- Missing BF-EHSI → `ABSTAIN`.
- Rain forecast alone does not trigger a fallow recommendation.
- No BF-EHSI recalculation.
- Cover-crop availability can add a limitation; no cover-crop suitability is invented.

### 3.7 Advisory fields

Every advisory has:

- `action`
- `status`
- `reason`
- `evidence`
- `limitations`
- `date`
- `cell_id`
- `crop_id`
- `growth_stage`

## 6. Bagian yang Sudah Local-Adapted

Local adaptation means the rules **can** consume Banyumas cell/context inputs; it does not mean the inputs are currently wired or calibrated.

- `cell_id` is carried into every tactical advisory.
- `EnvironmentContext` accepts Banyumas H3 ID, soil moisture, FC/WP/saturation, slope, drainage, salinity, PVRS/BF-EHSI, observation time.
- Irrigation now uses sequential H+1–H+3 storage, crop/stage Kc, explicit effective rainfall, ETo, runoff, percolation.
- Harvest uses planting date + duration; no unsourced maturity claim.
- Drainage uses storage/saturation, not rain alone.
- Fallow uses supplied BF-EHSI.
- Strategic rotation remains independent of forecast.

**Actual Banyumas local data is not yet wired into these inputs.** The interface accepts it, but the repository has no adapter from `EnvironmentContext` to the static H3 indicator file.

## 7. Local Calibration Status

### 7.1 Calibrated empirically

**None.** There is no Banyumas field dataset with paired crop observations, water use, N response, drainage, or yield trials in the repository.

### 7.2 Local-adapted but not calibrated

- Cell ID and environment inputs: accepted but not populated from a local adapter.
- Crop Kc/root/phase values: generic national/FAO, not local calibration.
- Irrigation rules: physically based daily balance, but coefficients/inputs not calibrated to Banyumas.
- Drainage/planting/harvest: rules are conservative and abstain/conditional when local thresholds are missing.

## 9. Limitations and Next Data Needs

### Limitations

- No actual Banyumas soil/weather/N/drainage datasets are wired.
- No Meteomatics forecast; only interface fields.
- Effective rainfall/runoff/percolation must be supplied; raw precipitation is not substituted.
- Crop registry has many `null` and proxy values.
- Harvest has no field maturity indicator; only calendar duration.
- No local drainage threshold.
- No local calibration.

### Next data needs

1. Banyumas H3 soil profile (FC, WP, saturation, Ksat, texture, pH, drainage class).
2. Local root-zone soil moisture in mm.
3. Meteomatics H+1–H+3 forecast plus effective rainfall/runoff/percolation derivation.
4. KATAM Banyumas planting calendar/windows.
5. Local crop phenology/Kc/root depth trials for Inpari 32, Anjasmoro, Vima-1, Sorgum.
6. Local N requirement/soil N/fixation observations.
7. Local drainage capacity/outlet condition.
8. Harvest maturity field indicators.
9. Local pest pressure.
10. Local yield, price, and cost data for integration/economics.

**Until these are available, the tactical advisor must continue to use `CONDITIONAL`/`ABSTAIN` where evidence is insufficient.**
